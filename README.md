# My personal portfolio in form of Website

Interactive portfolio built as a Windows XP simulation

**Live demo:** [vesjir-webfolio.vercel.app](https://vesjir-webfolio.vercel.app)

## Easter eggs

Try typing `format c:` in the Command Prompt

## Tech stack

- React + TypeScript
- Zustand
- Vite
- CSS

## Run locally

```bash
git clone https://github.com/vesely-jiri/Webfolio.git
cd webfolio
npm install
npm run dev
```
